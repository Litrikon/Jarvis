# ДЖАРВИС — персональный ИИ-ассистент на собственном ПК

Полностью локальный (приватный) ИИ-ассистент для Windows: мозг —
**Qwen3.8-27B** (GGUF, `llama.cpp`), глаза — мультимодальный mmproj,
уши — `whisper.cpp`, голос — `piper` (Ирина), руки — PowerShell и
нативный ctypes. Никаких облаков: всё считается на домашней видеокарте.

```
                    ┌──────────────────────────────────────────┐
                    │                ПК (Windows)              │
                    │                                          │
 Шеф голосом ────►  │  chat_server.py :8123 ◄── jarvis.py      │
 и текстом (браузер,│   веб-чат + /api/asr      Telegram-бот   │
 кнопка микрофона)  │                                          │
 Шеф текстом  ───►  │        │                      │          │
 (Telegram)         │        ▼                      ▼          │
                    │   llama-server :1234  (Qwen3.8-27B,      │
                    │   GPU + mmproj-зрение, llama.cpp)        │
                    │        │                                 │
                    │        ▼                                 │
                    │   инструменты: PowerShell, окна/мышь,    │
                    │   whisper, скриншоты+зрение, файлы,      │
                    │   память фактов, скиллы                  │
                    └──────────────────────────────────────────┘
```

## Что умеет (v3.8.3)

- **Двухканальное общение**: Telegram-бот + локальный веб-чат
  (`127.0.0.1:8123`), единая история диалогов, зеркало сообщений.
- **Зрение**: фото и скриншоты (Ctrl+V в веб-чате, фото из Telegram)
  понимаются мультимодальным mmproj: «прочитай текст с картинки»,
  «сравни настройки со скриншота».
- **Уши**: голосовые из Telegram и кнопка 🎤 в веб-чате расшифровываются
  локальным `whisper.cpp` (small, ~2 сек на фразу); любой аудио/видео
  файл — командой «расшифруй файл».
- **Файлы**: принимает из обоих каналов (до 100 МБ), складывает во
  «Входящие», читает текст, смотрит картинки, умеет сделать из файла
  новый скилл.
- **Руки**: полный контроль ПК — PowerShell, запуск/закрытие программ,
  окна/мышь/клавиатура (нативный ctypes), скриншоты, управление
  электропитанием, чистка диска, архивы, таймеры, расписание.
- **Ученик**: ведёт память фактов о владельце и пишет себе скиллы
  (папка `skills/`) после нетривиальных задач.
- **Честность как архитектурный принцип**: «файл-страж» и «страж путей»
  не дают модели выдумать содержимое файла, названного в сообщении, —
  ответ без инструмента перезапрашивается. Заявил «сделал» без вызова
  инструмента — модель сама признаётся.

## Технологии

| Компонент | Что | Почему |
|---|---|---|
| Мозг | `llama.cpp` server + Qwen3.8-27B GGUF (Q3_K_XL) + mmproj | локально, GPU, зрение |
| Уши | `whisper.cpp` (ggml-small, CPU) + ffmpeg | локально, русский |
| Голос | `piper` (ru_RU irina medium) | локально, быстрый |
| Каркас | чистый Python 3.12 stdlib (urllib, http.server, ctypes, tkinter) | без фреймворков |
| Каналы | python-telegram-bot-совместимый API (raw urllib), веб-чат на нативном http.server | |

## Структура

```
jarvis.py            ядро-агент: Telegram, инструменты, память, стражи,
                     циклы (watchdog, игра→выгрузка VRAM, брифинги)
chat/chat_server.py  веб-чат: стриминг токенов, /api/asr, /api/upload,
                     файловая панель, канал ИИ-ИИ (GLM как коллега)
chat/index.html      интерфейс: диалог, файлы, кнопка 🎤, drag&drop
win_ctl.py           окна/мышь/клавиатура через ctypes (user32)
skills/              скиллы-инструкции, которые Джарвис пишет себе сам
config.example.json  шаблон конфигурации (секреты — в config.json,
                     он в гит не входит)
```

## Запуск (у себя)

1. Windows, Python 3.12, `llama.cpp` (llama-server + mmproj), модель
   GGUF, `whisper.cpp`, `piper` с русским голосом.
2. Скопировать `config.example.json` → `config.json`, заполнить токен
   Telegram-бота, chat_id и пути к бинарникам/моделям.
3. `pythonw jarvis.py` — агент + Telegram; веб-чат поднимется сам на
   `127.0.0.1:8123` (голосовой ввод — кнопка микрофона, озвучка — piper).

## Философия проекта

- Приватность: ни один байт не уходит в чужие облака — ни текст, ни
  голос, ни картинки.
- Честность: ассистент не имеет права отвечать о файле/системе, не
  проверив её инструментом; «выдумка» перехватывается на уровне каркаса.
- Автономность: сам поднимает свой мозг (llama-server), сам следит за
  VRAM (перед игрой выгружается, после — возвращается), сам ведёт
  журнал и память.

## Статус

Личный проект, развивается итерациями (задачи 1–103 во внутреннем
worklog; журнал ведётся на машине владельца).
Публикуется как портфолио архитектуры локального ассистента. Никаких
гарантий; код привязан к конкретной машине и выкладан «как есть».
