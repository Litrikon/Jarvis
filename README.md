# ДЖАРВИС — персональный ИИ-ассистент на собственном ПК

Локальный (приватный по умолчанию) ИИ-ассистент для Windows: мозг —
**Qwen3.8-27B** (GGUF, `llama.cpp`), глаза — мультимодальный mmproj,
уши — `whisper.cpp`, голос — **Silero v5_6** (48 кГц; piper — резерв),
руки — PowerShell, нативный ctypes и UI Automation. Всё считается на
домашней видеокарте; в облако уходит только явное «спроси у старших».

```
                    ┌──────────────────────────────────────────┐
                    │                ПК (Windows)              │
                    │                                          │
 Шеф голосом ────►  │  chat_server.py :8123 ◄── jarvis.py      │
 и текстом (браузер,│   веб-чат, /api/asr (уши),              │
 кнопка микрофона)  │   /api/tts (голос)       Telegram-бот   │
 Шеф текстом  ───►  │        │                      │          │
 (Telegram)         │        ▼                      ▼          │
                    │   llama-server :1234  (Qwen3.8-27B,      │
                    │   GPU + mmproj-зрение, llama.cpp)        │
                    │        │                                 │
                    │        ▼                                 │
                    │   инструменты: PowerShell, окна/мышь,    │
                    │   UIA-элементы, скриншоты+зрение,        │
                    │   API-запросы, файлы, память+уроки,      │
                    │   скиллы, дневник                        │
                    └──────────────────────────────────────────┘
        «спроси у старших» ──► облачный ИИ (явная команда, опционально)
```

## Что умеет (v3.17.2)

- **Двухканальное общение**: Telegram-бот + локальный веб-чат
  (`127.0.0.1:8123`), единая история диалогов, зеркало сообщений.
- **Думает всегда**: любой вопрос идёт с размышлениями модели —
  бездумных быстрых ответов нет (v3.14.5).
- **Старшие братья**: «спроси у старших» — вопрос уходит облачному ИИ
  (бесплатный Pollinations без ключа или платный по `cloud_api_key`);
  без явной команды — всё строго локально.
- **Зрение**: фото и скриншоты понимаются мультимодальным mmproj —
  «прочитай текст с картинки», «сравни настройки со скриншота».
- **Уши**: голосовые расшифровываются локальным `whisper.cpp`;
  любой аудио/видео файл — командой «расшифруй файл».
- **Голос**: Silero v5_6 — пять голосов (Ксения, Ксеня, Байя, Евгений,
  Айдар), 48 кГц, автоударения, интонация вопросов; **цифры словами**
  («десятое ноября две тысячи двадцать шестого года»), правильное
  ударение «джАрвис»; «ответь голосом [имя]» в любом канале; piper —
  автоматический резерв.
- **Руки**: полный контроль ПК — PowerShell, запуск/закрытие программ,
  окна/мышь/клавиатура (нативный ctypes), **элементы интерфейса как
  текст** («элементы_окна») и нажатие по имени («клик_элемент», UI
  Automation), скриншоты с **дорисованным курсором** и координатами,
  кроп «область», чистка диска, архивы, таймеры, расписание.
- **API-запросы**: инструмент «запрос» — прямой HTTP к любому API
  (роутер, Netdata, сервисы) без PowerShell; «найти_на_странице» —
  точный поиск по тексту страницы или открытого браузера.
- **Ученик**: ведёт память фактов о владельце, пишет себе скиллы
  (папка `skills/`) и **уроки опыта** (`memory/lessons.json`:
  что сработало → ок, что упало → сбой) — релевантные уроки
  инъектируются в промпт.
- **Дневник**: обмены, вытесненные из окна памяти, складываются в
  `diary.jsonl` — ассистент поднимает их инструментом «дневник»,
  длинная нить диалога не теряется.

## Честность как архитектурный принцип

Ответ языка-модели — не факт, а гипотеза. Каркас проверяет каждый:

| Страж | Ловит |
|---|---|
| файл-страж | «прочитал файл», не вызвав инструмент чтения |
| трос действий | «сохранил/создал/записал в память» без вызова |
| план-гард | «сейчас сделаю…» текстом вместо вызова |
| руки-трос | «передвинул/кликнул/напечатал» без инструмента рук |
| фантом-результат | «инструмент вернул НЕ подтвердилось» при нуле вызовов |
| приказ-гард | приказ на действие, а за ход не было ни одного вызова |
| мышь-страж | вопрос «где сейчас мышь» без вызова скрина/области (v3.14.3) |
| страж повторов | 3 одинаковых вызова подряд — коррекция, 6 — честная остановка (v3.14.1) |

Каждый страж даёт один перезапрос модели, потом — честный отказ.
Мышь и окна проверяют каждое действие чтением факта: «проверено»
или «НЕ получилось» — третьего не бывает.

## Надёжность (v3.17.2)

- **Ротация логов**: `jarvis.log` и `llama.log` ротируются (~3 МБ,
  хвост сохраняется) — логи не растут вечно.
- **Фолбэк связи**: Telegram-канал через прокси молчит 3 раза —
  автоматический уход на прямое соединение; прямое плавает 6 раз —
  возврат на прокси. Ассистент не замолкает вместе с прокси.
- **Глубокая память**: окно истории 32 сообщения + жёсткий бюджет
  28К символов (контекст LLM не переполняется на длинных цепочках
  инструментов) + дневник для вытесненного.
- **Самопроверка ежедневно в 12:00**: живой прогон стражей честности,
  мозга, зрения (тест-картинка с контрольными цифрами), поиска,
  файлов и связи; провал приходит владельцу в Telegram, полный
  отчёт — в журнал. На старте самопроверка **ждёт готовности мозга**
  (v3.17.2): свежий процесс — до 15 минут, обычный полдень — до 3;
  сон мозга — честный SKIP; не поднялся за окно — тревога настоящая.
- **Самовосстановление**: планировщик задач перезапускает агента при
  падении; внутри агента 6 фоновых циклов — диски (мало места),
  события (RAM на исходе, перегрев, GPU под нагрузкой), игры с
  автовыгрузкой VRAM, ярлыки VRAM, утренний брифинг (8:00),
  самопроверка (12:00). Мозг поднимается сам с деградацией
  «GPU+зрение → GPU → CPU-аварийный»; чат-сервер сторожится и
  перезапускается собственным стражем (chat-watch).

## Безопасность

- **Законы Шефа** — жёсткие запреты уровнем кода (не промпта):
  З1 пароли (смена/создание/ввод — никогда), З2 деньги (платежи,
  переводы, кошельки — никогда), З3 необратимое (форматирование, снос
  программ, правка реестра — только после явного «да» владельца).
- **Секреты вне репозитория**: `config.json` (токен бота, креды)
  в гит не входит — только `config.example.json` с заглушками.
- **Веб-чат слушает только 127.0.0.1**, Telegram-бот игнорирует
  чужие chat_ids, каждая опасная команда журналируется.

## Технологии

| Компонент | Что | Почему |
|---|---|---|
| Мозг | `llama.cpp` server + Qwen3.8-27B GGUF (Q3_K_XL) + mmproj, KV-кэш q8_0 + flash-attention | локально, GPU, зрение, контекст 12288 в 16 ГБ VRAM |
| Уши | `whisper.cpp` (ggml-small, CPU) + ffmpeg | локально, русский |
| Голос | **Silero v5_6_ru** (48 кГц, 5 голосов, автоударения, цифры словами), piper — резерв | локально, реалистичный |
| Каркас | чистый Python 3.12 stdlib (urllib, http.server, ctypes, UIA) | без фреймворков |
| Каналы | Telegram Bot API (raw urllib) + веб-чат на http.server | |
| Старшие братья | облачный ИИ по API (Pollinations / GLM / Mistral) | только явное «спроси у старших» |

## Структура

```
jarvis.py            ядро-агент: Telegram, инструменты, память, стражи
                     честности, 6 фоновых циклов, самопроверка
chat/chat_server.py  веб-чат: стриминг токенов, /api/asr, /api/tts,
                     /api/upload, карточки скачивания файлов
chat/index.html      интерфейс: диалог, файлы, кнопка 🎤, drag&drop
win_ctl.py           окна/мышь/клавиатура через ctypes (user32)
install_silero.py    самоустановка Silero (torch + numpy + модель)
router_api.py        Keenetic-роутер через родной API (NDW4)
torrent_ctl.py       uTorrent: список/удаление с верификацией
hwinfo_sensors.py    датчики HWiNFO через shared memory (SM2)
tools/lora/          рецепт LoRA-дообучения (README_LORA + датасет)

config.example.json  шаблон конфигурации (секреты — в config.json,
                     он в гит не входит)
```

## Запуск (у себя)

1. Windows, Python 3.12, `llama.cpp` (llama-server + mmproj), модель
   GGUF, `whisper.cpp`; голос — `python install_silero.py` (или
   команда «поставь silero» самому Джарвису — самоустановка);
   piper — необязательный резерв.
2. Скопировать `config.example.json` → `config.json`, заполнить токен
   Telegram-бота, chat_id и пути к бинарникам/моделям.
3. `pythonw jarvis.py` — агент + Telegram; веб-чат поднимется сам на
   `127.0.0.1:8123` (голосовой ввод — кнопка микрофона, озвучка —
   Silero). Автозапуск — задачей планировщика с триггером «вход в
   систему».

## Философия проекта

- **Приватность по умолчанию**: текст, голос и картинки не покидают
  дом; в облако уходит только явное «спроси у старших» (выключается
  в `config.json`).
- **Честность**: ассистент не имеет права отвечать о файле/системе,
  не проверив её инструментом; выдумка перехватывается каркасом.
- **Автономность**: сам поднимает свой мозг, сам себя сторожит, сам
  проверяет себя раз в сутки, сам возвращается после сбоя.

## v3.11.0 — Генерация фото и видео без цензуры (Task 129, 07.11.2026)

Приказ Шефа: «мне нужна модель ИИ, которая генерирует фото и видео и без
цензуры! Qwen — только текстовая модель!»

**Почему нужен движок:** текстовая LLM (Qwen/llama) физически не умеет
создавать изображения — это другой класс моделей (диффузионные). Поэтому
рядом с мозгом на той же видеокарте стоит **ComfyUI** — стандартный
локальный движок генерации (AMD ROCm, RDNA4), а внутри него — модели без
цензуры:

- **FLUX.1-dev** (GGUF Q4_K_S) — фото-флагман, ~1 мин на кадр 1024×1024
- **RealVisXL V5.0** (SDXL) — быстрое фото по слову «быстро:», ~20-30 с
- **Wan 2.2 TI2V-5B** (GGUF Q6_K) — видео 480p ~5 с, генерация несколько минут

Всё локально и приватно: никаких облаков, ключей и внешних цензоров.

**Команды (Telegram и веб-чат):**
- «переключись на фото» / «переключись на видео» — включить режим
  (мозг выгружается из видеопамяти, генератор поднимается ~15-60 с)
- в режиме генерации любое сообщение = описание кадра/ролика
- «нарисуй …» / «сделай видео …» — переключение и генерация сразу,
  без отдельной команды
- «быстро: …» — ускоренное фото (RealVisXL вместо FLUX)
- «верни основную» / «обычный режим» — обратно мозг Qwen
- «статус» — показывает режим генератора

**Технически:** gen-команды разбираются до power-команд («выключи фото»
не выключает ПК); llm_start не поднимает мозг при живом генераторе
(защита от watchdog/игр); фото — sendPhoto, видео — файлом; движок
поднимается `comfy_headless.bat` (порт 8188), модели — в
`D:\Jarvis\comfyui_rocm\models`. Краш старта ComfyUI на машинах без
MSVC лечится удалением flash_attn/amd-aiter (ck-attention быстрее для
RDNA4). Юнит-маршрут gen_route: 26/26 в песочнице, 8/8 на живом ПК2.

## v3.11.1 — Фикс генерации + понятные ошибки (Task 129.2, 07.11.2026)

Доклад Шефа: «не получается сгенерировать фото».

**Причина:** текстовый энкодер FLUX (t5xxl) скачался с верным размером, но
побитым содержимым (два параллельных curl писали в один файл) — ComfyUI
падал молча. Файл перезакачан и проверен живой генерацией.

**Что изменилось:**
- при ошибке генерации приходит конкретная причина (узел + суть), а не
  «смотри логи»;
- перед генерацией проверяются файлы моделей — «ещё докачивается, N%»
  вместо загадочного сбоя; «статус» показывает прогресс докачки;
- имена входов нод подогнаны под свежую сборку ComfyUI (ckpt_name у
  RealVisXL, video у SaveVideo) — «быстро:» и видео проверены живьём;
- русские запросы на «быстро:» автоматически идут через FLUX (RealVisXL
  понимает только английский — проверено: русский промпт давал случайный
  портрет вместо заказанного пейзажа), в подписи фото честная пометка.

**Живые тесты:** FLUX 1024×1024 — 66 с; RealVisXL — 30 с (без OOM после
FLUX — динамическая VRAM справляется); картинки проверены VLM (9/10).
