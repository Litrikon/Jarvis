# Скилл: Перенос папок
Описание: перенести папку/файлы между дисками с проверкой целостности

## Когда
«перенеси X на D», освобождение диска C (в паре со скиллом cleanup).

## Как
1. Основной путь: «перенести» {"от":"C:\...","куда":"D:\..."} — робастный, внутри всё есть.
2. После переноса — ПРОВЕРКА (число файлов и объём):
   run_ps: (Get-ChildItem 'D:\куда' -Recurse -File -EA SilentlyContinue | Measure-Object Length -Sum) | ForEach-Object { '{0} файлов, {1:N2} ГБ' -f $_.Count,($_.Sum/1GB) }
   Сравни с источником. Расхождение больше 1% — скажи Шефу, источник НЕ удаляй.
3. Перенос больше 50 ГБ или системных папок — сначала подтверждение Шефа (правило промпта).
4. Итог: «перенёс N файлов, X ГБ, источник не тронут / удалён».

## Грабли
- Никогда: D:\Jarvis, кэш моделей, C:\Windows, Program Files.
- Проверь «место» на диске-назначении: влезет с запасом 10%.
- Занятые открытыми программами файлы не едут — закрой программу, повтори.
