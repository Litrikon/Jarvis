Скилл: мышь и окна (v3.7.0 «ЧЕСТНЫЕ РУКИ»)

Описание: управление мышью, окнами и клавиатурой БЕЗ вранья — инструменты
сами проверяют каждое действие и докладывают Шефу только подтверждённые
факты. Здесь же — координатный контракт: какие пиксели правильные.

КОГДА
-----
- Шеф просит кликнуть, навести, перетащить, прокрутить.
- Шеф просит закрыть/свернуть/развернуть/передвинуть окно.
- Управление программой с интерфейсом: AMD Adrenalin, браузер, лаунчер,
  игра, настройки Windows.
- После моего клика что-то пошло не так — надо проверить, что реально
  произошло.

КАК
---
1. КООРДИНАТНЫЙ КОНТРАКТ (главное):
   - экранные координаты беру ТОЛЬКО со свежего скриншота («скрин»);
   - скриншот и мышь живут в одной системе — ФИЗИЧЕСКИХ пикселях,
     0,0 = левый верхний угол;
   - НЕ дели и не умножай координаты на масштаб Windows — скрин уже
     в физических пикселях, бери точку прямо с него;
   - экран у нас 3840x2160 физических (масштаб Windows 250%, логические
     1536x864 — это НЕ для мыши); если точка получилась крошечной
     (например, 350,260 на 4K) — почти наверняка перепутал масштаб,
     пересмотри скрин.
2. Цепочка управления GUI: «окна» → «окно активировать» → «скрин» →
   координаты по скриншоту → «мышь»/«клавиша»/«печатать» → «скрин»
   для проверки результата.
3. Читай ответ инструмента буквально (закон З6):
   - «OK … проверено» — действие подтверждено чтением состояния Windows
     (позиция курсора прочитана назад / окно исчезло / фокус на месте);
   - «НЕ получилось / НЕ подтвердилось» — действие НЕ состоялось.
     Скажи Шефу правду и пробуй другой путь: клавиша, alt+tab,
     «окно» с другим действием, run_ps.
   - Никогда не говори «нажал/закрыл/сделал», если инструмент не
     ответил «OK … проверено».
4. Закрытие окна: после WM_CLOSE я жду до 1.6 с и проверяю, что окно
   исчезло. Приложение с несохранёнными данными останется живым
   (диалог сохранения) — увижу и честно доложу.
5. Клик пришёлся, но эффекта нет: сделай «скрин» и посмотри глазами —
   возможно, кнопка неактивна, открылся диалог или нужен двойной клик.
