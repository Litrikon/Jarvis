# Скилл: мышь_и_окна
Описание: Точные клики мышью, движение и ввод текста в нужное место на 4K — координатный контракт, прицел (UIA → кроп-зрение → скрин), печать без каретки для WinUI, проверка после каждого шага; проверено живьём на Калькуляторе, Блокноте и Telegram (Unigram), Task 134.

Написан Джарвису по приказу Шефа 08.11.2026 (Task 134: «научи его движению мыши,
нажатию кнопок и вводу текста в нужное место»). Всё ниже — из живых тестов этой
ночи, координаты и грабли настоящие.

## 1. Координатный контракт (экран Шефа)
- 3840x2160 ФИЗИЧЕСКИЕ пиксели (масштаб Windows 250%, логические 1536x864).
  Мышь и скрины работают ТОЛЬКО в физических.
- Сжатый «скрин» (1600px): координаты из его описания умножай на фактор 2.4.
  Для точного прицела — «область» (кроп 1:1 без сжатия).
- Результат «скрин»/«область» всегда несёт ТОЧНУЮ позицию курсора текстом —
  бери её, не угадывай по картинке.

## 2. Прицел: порядок надёжности
1. «элементы_окна» (UIA): имена + ClickablePoint. У чатов Unigram имя строки
   = «Имя, превью, Отправлено/Получено в …» — ЗАПЯТАЯ после имени = превью =
   настоящий чат/Избранное; просто «Избранное» без запятой — канал-тёзка!
2. Кроп 1:1 («область»/PIL) + зрение: вопрос НЕЙТРАЛЬНЫЙ — «перечисли строки:
   имя|X,Y, как написано, НЕ выдумывай». НАВОДЯЩИЙ вопрос («это же Избранное,
   да?», «пометь строку с закладкой») — зрение ПОДДАКНЕТ и покажет ерунду
   (живой прокол: пометило «Архив» как «Избранное»).
3. Полный «скрин» — только общий вид, координаты там грубые (x2.4).

## 3. Цикл работы (главное правило)
окна/запустить → «окно» активировать → прицел → «мышь» клик → ПРОВЕРИТЬ
(элементы_окна / кроп-зрение / скрин) → следующий шаг. После КАЖДОГО клика —
проверка; два промаха = менять подход (кроп точнее, клавиатура, run_ps).
Движение и клики сами читают позицию курсора из ОС — «OK … проверено» = правда.

## 4. Ввод текста (проверено: Блокнот 122 симв. 1:1; Unigram «Привет» доставлен)
- Обычные окна (Блокнот): «печатать» сам ставит каретку авто-кликом в центр
  окна. Сверка текста: Ctrl+A → Ctrl+C → Get-Clipboard (буфер = эталон 1:1).
- WinUI/UWP (Unigram, UWP-настройки): каретки НЕТ ВОВСЕ — «печатать» без
  каретки честно отказывает. Рецепт: кликни в поле по UIA-точке (или кропу),
  подтверди поле (UIA Edit + HasKeyboardFocus / кроп-зрение видит поле) и
  печатай с {"обойти_каретку":"да"} (v3.14.4). Сверка: UIA ValuePattern поля
  (value="Привет") или кроп низа окна глазами.
- ЖЕЛЕЗНО: НЕ жми Enter, пока текст в поле НЕ подтверждён (UIA value или
  кроп). Enter отправляет безвозвратно.

## 5. Рецепты программ (живые тесты 08.11)
- КАЛЬКУЛЯТОР: запустить calc.exe → UIA кнопки «Семь»/«Умножить на»/«Восемь»/
  «Равно» с ClickablePoint → 4 клика мышью → результат в UIA («Отображать
  как 56»). Кнопки ~190x128 px, промахов 0/4. Закрытие — «окно» закрыть.
- БЛОКНОТ (Win11): ВНИМАНИЕ — восстанавливает ПРОШЛЫЕ вкладки (мне открылся
  журнал!). Перед печатью сверяй заголовок вкладки; черновик — только в
  явном новом файле/пустой вкладке. НИКОГДА не Ctrl+S в чужой вкладке (можно
  затереть файл!). Закрытие изменённой вкладки — встроенный диалог (кнопки
  в окне); пустая вкладка закрывается alt+f4 без диалога. Несохранённый
  буфер старой вкладки — мусор сессии, файл на диске он не трогает, пока не
  сохранят.
- TELEGRAM (Unigram, окно стабильно 97,80 2592x2017):
  * Вкладки папок y≈300: «Все чаты» (~263), «Личные» (521), «Новые», «Курган».
  * «Избранное» живёт в папке «Личные» — первая строка, UIA имя с превью,
    точка ~(570,446). В «Все чаты» оно ГЛУБОКО по времени последних сообщений.
  * Поле «Сообщение» — центр ~(1784,2000), UIA Edit «Сообщение».
  * После открытия чата UIA-дерево ОТСТАЁТ на секунды — жди поле циклом
    (до 15-20 с), наведение мыши на поле помогает элементу появиться.
  * Печать только через обойти_каретку (WinUI) + проверка поля.
- ГРАБЛИ Unigram (все пойманы живьём): поиск ПОМНИТ прошлый запрос (очищай
  Ctrl+A,Delete); в глобальных результатах КАНАЛЫ-тёзки («Избранное со
  смыслом», «…Геворгян. Избранное.») — после клика проверь: кнопка
  ПРИСОЕДИНИТЬСЯ / «Вкл. звук» / нет поля = КАНАЛ, ESC и дальше; первая
  строка «Архив» открывает архив БЕЗ поля ввода; скролл списка — проверяй
  смену первой строки (знак «сколько» иногда наоборот); UIA-дерево может
  «не видеть» элементы, которые на экране есть — тогда кроп-зрение.

## 6. Замеры точности (Task 134, живьём)
- Движение: 12/12 целей по всему экрану, отклонение 0 px (SetCursorPos с
  обратным чтением позиции).
- Клики: Калькулятор 4/4 в кнопки 190x128; Unigram — в строку чата и поле.
- Печать: Блокнот — 122 символа, буфер = эталон 1:1; Telegram — «Привет»
  доставлен в Избранное (UIA чата: «Привет, Отправлено в 2:12»).
