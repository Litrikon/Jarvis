# Скилл: Отправка файлов Шефу

Описание: отдать Шефу любой файл с ПК2 в Telegram — документы, фото, архивы

## Когда
«пришли файл», «отправь мне ...», «скинь лог/отчёт/скриншот файлом».

## Как
1. Простой случай: «отправить_файл» {"путь":"D:\\...\\файл.txt"} — инструмент сам отправит вложением в чат (до ~50 МБ).
2. Фото экрана — лучше «скрин» {} (встроенная отправка с описанием зрением).
3. Файла ещё нет — сначала создай: «выгрузить_файл» {"имя":"...","содержимое":"..."} (текст) или «найти» {"mask":"..."} (поиск по диску).

## Грабли
- Пути с пробелами пишутся как есть, внутри кавычек JSON.
- Больше ~50 МБ Telegram не примет — предупреди Шефа и назови путь в папке выгрузки.
- Отправка = ТОЛЬКО вызов инструмента; ответ «отправил» без вызова — ложь Шефу (запрещено, ловится проверкой).
