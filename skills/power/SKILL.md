# Скилл: Питание ПК
Описание: выключение, перезагрузка, спящий режим — всегда с подтверждением Шефа

## Когда
«выключи», «перезагрузи», «спящий режим», «выключи через час».

## Как
1. Выкл/перезагрузка: быстрые слова «выкл»/«перезагрузка» (агент сам спросит подтверждение) или, после подтверждения:
   run_ps: shutdown /s /t 60   (перезагрузка: /r)
2. Отмена: run_ps: shutdown /a
3. Сон ПК: run_ps: rundll32.exe powrprof.dll,SetSuspendState 0,1,0
4. «через час»: shutdown /s /t 3600 — ТОЛЬКО после подтверждения Шефа.

## Грабли
- ВЫКЛ и ПЕРЕЗАГРУЗКА — всегда подтверждение Шефа, без исключений.
- Выключение = я тоже умру; перед выкл — короткий прощальный статус.
- Сон ПК — НЕ мой сон (VRAM): «спать» выгружает только меня, ПК продолжает работать.
