# Скилл: Программа передач (ТВ)
Описание: «что идёт по первому/России/ТНТ», расписание канала на сегодня/вечер

## Когда
Любой вопрос про телепрограмму: «программа передач», «что сейчас по ТВ», «что вечером по …», «расписание канала».

## Как
1. Лучший источник — САЙТ САМОГО КАНАЛА: Первый — https://www.1tv.ru/schedule (расписание дня, читается по HTTP). Другие каналы: «интернет» {"запрос":"<канал> официальный сайт телепрограмма"} и взять домен самого канала.
2. Второй источник: tv.mail.ru — «интернет» {"запрос":"<канал> программа передач site:tv.mail.ru"} и открыть ссылку из выдачи.
3. «открыть_ссылку» {"url":"..."} вернёт текст расписания (время + названия передач).
4. Ответ Шефу: ближайшие по времени 5-7 передач «ЧЧ:ММ — название», начиная с текущего времени; длинный список не пересказывай целиком.

## Грабли
- debilizator.tv из России ЗАКРЫТ (HTTP 451) — не открывай его, даже если он в выдаче: получишь заглушку.
- tv.yandex.ru по HTTP отдаёт пустой каркас (JS) — не годится для чтения.
- Сайт ответил 451 — он закрыт для российских IP: Chrome не поможет, возьми ДРУГУЮ ссылку из выдачи.
- Расписание — только из текста страницы, не из памяти (З6).
