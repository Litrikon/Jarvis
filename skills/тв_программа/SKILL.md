# Скилл: Программа передач (ТВ)
Описание: «что идёт по первому/России/ТНТ», расписание канала на сегодня/вечер

## Когда
Любой вопрос про телепрограмму: «программа передач», «что сейчас по ТВ», «что вечером по …», «расписание канала», «что по НТВ».

## Как (v3.25.1, Task 165)
1. ЕДИНСТВЕННЫЙ правильный путь — инструмент «телепрограмма» {"канал":"НТВ"}: прямой HTTP к tv.mail.ru, расписание дня в чистом виде (время + названия), показывает от текущего времени. Работает мгновенно, без браузера.
2. «вечером» / «вечер» — добавь {"когда":"вечер"}: покажет передачи с 18:00.
3. Ответ Шефу: ближайшие 5-8 передач «ЧЧ:ММ — название»; длинный список не пересказывай целиком.

## Грабли (живые, 12.11)
- НЕ ИЩИ программу через «интернет»: поиск ведёт на tvline.ru (мусор без расписания), ntv.ru/tvp отдаёт 404-заглушку, /extract на tvline отдаёт 502 — ход умирает на лимите шагов. Инструмент «телепрограмма» уже знает правильный источник.
- debilizator.tv из России ЗАКРЫТ (HTTP 451) — не открывай его.
- tv.yandex.ru по HTTP отдаёт пустой каркас (JS) — не годится.
- Расписание — только из свежего ответа инструмента, не из памяти (З6).
