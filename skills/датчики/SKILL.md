Скилл: датчики (HWiNFO)

Описание: живые температуры, обороты и мощности GPU/CPU/платы/дисков из HWiNFO — инструмент «датчики», мгновенно и без открытия программ.

КОГДА
-----
- Шеф спрашивает: «сколько видеокарта», «температура GPU/CPU», «как греется»,
  «обороты вентиляторов», «мощность».
- События: перегрев, длинная нагрузка — Events уже берут градусы отсюда.

КАК
---
- Инструмент «датчики» {} — компактная сводка одной строкой секциями:
  GPU (температура + память-точка, кулер RPM/PWM, мощность/частоты),
  CPU (Tdie, PPT, частота), плата (System, вентиляторы), диски (SMART °C).
- Данные читаются ПРЯМО из памяти работающего HWiNFO64 (shared memory
  «HWiNFO_SENS_SM2», формат SM2). Ничего не запускать, не открывать,
  не «смотреть глазами» — тем более НЕ открывать Adrenalin.

ФАКТЫ (наше железо)
-------------------
- GPU: AMD Radeon RX 9070 XT — метки HWiNFO: «GPU Temperature»,
  «GPU Memory Junction Temperature», «GPU Fan» (RPM), «GPU Fan PWM»,
  мощности VDDCR_GFX и пр., «GPU Memory Clock».
- CPU: Ryzen 5 5600 — «Tdie», «CPU Package Power (PPT)», «CPU Clock».
- Плата: GIGABYTE B550 AORUS ELITE (ITE IT8689E) — System temp, вентиляторы.
- Диски: SMART-температуры C:/D:/E:/F:.
- Всего ~198 показаний; events_loop опрашивает их раз в 2 минуты и
  уведомляет: GPU >85°C дольше 5 мин, полная нагрузка GPU 15+ мин
  (с реальной температурой в уведомлении).

ГРАБЛИ
------
- «Датчики пусты» = HWiNFO64 не запущен (должен висеть в трее, автозапуск)
  или выключен Shared Memory Support (у нас включён: SensorsSM=1 в INI).
- Юниты берём из моей карты типов (°C, RPM, Вт, МГц, В, %) — родные
  строки HWiNFO иногда в кривой кодировке.
- Не выдумывай значения: нет строки — так и скажи, чего нет.
- Adrenalin для температуры больше не нужен (Шеф, 02.11: «это можно всё
  брать с HWiNFO»).
