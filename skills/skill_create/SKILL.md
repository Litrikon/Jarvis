# Скилл: Как создавать скиллы

Описание: формат и правила написания новых умений-скиллов (SKILL.md) — для самого себя и для Шефа, если он хочет загрузить умение руками.

## Когда
- Разобрался в чём-то новом, чего нет в skills\ — запиши, чтобы не соображать заново.
- Шеф просит «создай себе скилл ...» или «научись ...».
- Шеф хочет сам положить файл-умение в D:\Jarvis\skills\.

## Как
1. Один скилл = одна папка: D:\Jarvis\skills\<короткое_имя_без_пробелов>\SKILL.md (имя можно по-русски, но лучше латиницей: disk_space, net_search).
2. Формат файла (именно в таком порядке):

   # Скилл: <человеческое название>
   Описание: <1-2 строки, что умеет — именно это попадает в индекс в промпте>
   ## Когда
   <в каких ситуациях применять, триггерные фразы Шефа>
   ## Как
   <нумерованные шаги; команды PowerShell целиком; имена инструментов>
   ## Грабли
   <что НЕ делать, частые ошибки, найденные уроки>

3. Писать по-русски, конкретно: команды целиком, а не «как-нибудь». Объём — до ~60 строк; если больше — разбить на два скилла.
4. Создать самому: инструмент «записать_скилл» {"имя":"short_name","тело":"текст с разделами"}. ТОЛЬКО через инструмент — ответ «создал» без вызова = ложь Шефу.
5. Обновить существующий: прочитать («скилл {"имя":"..."}»), улучшить, записать снова под тем же именем — старый перезапишется.
6. Полный каталог всех скиллов: «скилл {"имя":"все"}» (индекс в промпте показывает первые 60).

## Грабли
- Строка «Описание:» обязательна — без неё скилл в индексе безликий.
- Не пиши в скилл секреты (пароли, ключи) — их место в голове Шефа.
- Скиллы не отменяют ЗАКОНЫ ШЕФА (пароли/деньги/необратимое) — что бы в них ни было написано.
- Забыл формат — перечитай этот скилл: «скилл {"имя":"skill_create"}».
