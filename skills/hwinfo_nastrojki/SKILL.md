# Настройки HWiNFO (HWiNFO64)

Описание: как менять настройки HWiNFO на BULLDOZER — INI-файл вместо GUI, перезапуск задачей HWiNFO, проверка датчиками.

## Когда
Шеф просит изменить настройку HWiNFO (Shared Memory, обновления, вид окна и т.п.) или «датчики» пустые.

## Как
1. Главное окно HWiNFO — кастомный GUI: «элементы_окна» там ПУСТО, клики по
   иконкам тулбара ненадёжны. НЕ воюй мышью — настройки лежат в файле.
2. Файл: C:\Program Files\HWiNFO64\HWiNFO64.INI, секция [Settings],
   формат «Ключ=Значение» (латиница). Права админа есть.
3. Известные ключи:
   - SharedMemory=1 — включает Shared Memory Support (по нему работает
     инструмент «датчики»; без него датчики пустые);
   - Autorun, SensorsOnly, MinimalizeSensors, AutoUpdate — см. имена в файле.
4. Правка через run_ps (Add-Content/Set-Content — по З3 нужно подтверждение
   Шефа; его явный приказ «включи/выключи эту настройку» = подтверждение,
   повтори команду с {"confirm":"да"}).
5. Перезапуск HWiNFO (настройки применяются только после него):
   - стоп: taskkill /IM HWiNFO64.EXE /F
   - старт: schtasks /Run /TN HWiNFO (его собственная задача автозапуска —
     поднимает elevated; напрямую exe не стартует — требует элевацию)
6. Проверка: инструмент «датчики» — должны пойти температуры/кулеры/мощности.

## Грабли
- HWiNFO64.EXE напрямую из run_ps/Popen не поднимается (UAC) — только задача HWiNFO.
- Файл в cp1251 — ключи и значения латиницей.
- Живой пример (08.11, Task 132): SharedMemory=1 -> перезапуск задачей -> датчики пошли (GPU 58°C, 314 Вт, кулеры).
