# Скилл: Поиск в интернете
Описание: свежие данные, новости, курсы, погода; чтение страниц по ссылке

## Когда
Любое «сейчас», «свежее», «курс», «погода», «новости», «кто такой ...».

## Как
1. «интернет» {"запрос":"..."} — поиск: заголовки, выдержки, ссылки. Формулировок можно пробовать несколько.
2. «новости» {"тема":"..."} — новости; пустая тема = главное в мире.
3. «курсы» {} — валюты и крипту точно (ЦБ РФ, Binance).
4. «открыть_ссылку» {"url":"..."} — прочитать страницу целиком.
5. Схема: поиск → открыть 1-2 лучшие ссылки → короткая выжимка Шефу со ссылкой.
6. Телепрограмма — отдельный скилл «тв_программа» (там проверенные источники).

## Грабли
- НЕ выдумывай свежие цифры из памяти — только через поиск.
- Ссылка не открылась — возьми другую из выдачи.
- Сайт ответил 451 — он закрыт для российских IP (debilizator.tv и др.): браузер НЕ поможет, тот же IP. Бери ДРУГУЮ ссылку из выдачи, а Шефу честно скажи, что домен из РФ закрыт.
- Русские сайты в выдаче обычно открываются лучше зарубежных.
