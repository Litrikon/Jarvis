# Скилл: Управление окнами и GUI
Описание: клики, ввод, перетаскивание, настройки в окнах программ по шагам

## Когда
Всё, что делается мышью: настройки, браузер, лаунчеры, AMD Adrenalin.

## Как
Цикл: «окна» → «окно» активировать → «скрин» посмотреть → «мышь»/«клавиша»/«печатать» → «скрин» проверить.
1. «окна» {} — найди нужное окно (кусок заголовка).
2. «окно» {"действие":"активировать","окно":"часть заголовка"}.
3. «скрин» {} — сначала УВИДЬ экран. Разрешение 2560x1440, (0,0) — левый верхний угол.
4. «мышь» {"действие":"клик","x":...,"y":...} — целься в центр элемента.
5. «печатать» {"текст":"..."} — только в АКТИВНОЕ поле (сначала клик в него).
6. Снова «скрин» — проверь результат. Не вышло — другой путь: другие координаты, «клавиша» tab/enter, или run_ps.

## Грабли
- Не бей вслепую: скрин → клик → скрин.
- Один промах — пробуй другой путь, не зацикливайся на одном варианте.
- Окно свернулось — «окно» {"действие":"восстановить",...}.
