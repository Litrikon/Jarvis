# Скилл: Отчёт по расписанию (при включении ПК / утром)
Описание: регулярный отчёт Шефу в Telegram — состояние ПК, диски, память, ошибки

## Когда
«настрой отчёт при включении ПК», «каждое утро присылай отчёт о железе», «отчёт о состоянии дисков по расписанию».

## Как (проверено Task 168, 14.11 — работает)
ГЛАВНОЕ ПРАВИЛО: НИКОГДА не собирай отчёт inline-командой в /TR (кавычки
ломаются, скрипт теряется — живой сбой 14.11). Только через .ps1-файл.

1. Скрипт отчёта: возьми ЗАГОТОВКУ D:\Jarvis\data\morning_report.ps1
   (уже рабочий: Windows/ЦП/память/диски/SMART/ошибки за сутки + отправка
   в ТГ с 5 ретраями). Для нового отчёта — скопируй под новым именем и
   правь секцию «Сборка текста».
2. Создай задачу (при включении ПК):
   run_ps: schtasks /Create /TN JARVIS_имя /SC ONSTART /DELAY 0002:00 /TR "powershell -WindowStyle Hidden -ExecutionPolicy Bypass -File D:\Jarvis\data\имя.ps1" /RU "BULLDOZER\litro" /F
   /DELAY 0002:00 = пауза 2 мин после включения (сеть должна подняться).
   Ежедневно в 8:00 = /SC DAILY /ST 08:00 (тогда без /DELAY).
3. Проверка: run_ps: schtasks /Query /TN JARVIS_имя
4. Тестовый прогон: run_ps: schtasks /Run /TN JARVIS_имя — и через 30 с
   проверь лог D:\Jarvis\data\имя.last.log (там OK или FAIL).

## Что собирать (просьба Шефа 14.11)
Windows (версия, аптайм), загрузка ЦП и памяти (ГБ и %), ВСЕ диски
(свободно/всего), здоровье дисков SMART, ошибки System-журнала за сутки
(сгруппировать по источнику, топ-3).

## Грабли
- /TR с вложенными кавычками — НЕ РАБОТАЕТ. Сложное действие = .ps1-файл.
- Отчёт «при включении» = /SC ONSTART (+ /DELAY), а НЕ /SC DAILY.
- Кириллица в .ps1 — файл в UTF-8 с BOM, иначе PS 5.1 покажет кракозябры.
- НЕ докладывай «готово», пока schtasks /Run не дал OK в .last.log
  (живой сбой 14.11: отчитался «готово» без скрипта — Шеф злой).
